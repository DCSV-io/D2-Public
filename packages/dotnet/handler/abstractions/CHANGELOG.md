## 0.1.5 - 2026-07-25
### API-breaking

- `IHandler<in TInput, TOutput>` constrains `TInput : notnull` - whole-input is never a nullable type argument;
  optional/absent values live on bag members.

### Added

- `HandlerOptions.ElevateScopes` (`IReadOnlySet<string>?`) - composition scopes elevated for the parent Execute window
  after `ScopeRequirement` passes (null/empty disables).
- `D2GeneratedHandlerScopeAttribute` / `D2HandlerScopeMode` markers for generated sealed DefaultOptions companions.
