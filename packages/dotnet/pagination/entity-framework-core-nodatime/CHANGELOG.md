## 0.2.0

### Changed

- An instant cursor key that does not parse now returns
  `LIB_PAGINATION_CURSOR_KEY_UNDECODABLE` rather than the anonymous validation
  failure, so a caller can tell an unreadable cursor position from every other
  paging rejection. `RoundTripExtendedIso` returns the same code on a failed
  round trip.
