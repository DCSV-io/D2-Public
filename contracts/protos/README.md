# `contracts/protos/`

Protocol Buffer contracts: the `.proto` files that define gRPC service interfaces and shared message types used across
.NET services and the TypeScript gRPC client.

## Layout

```
contracts/protos/
├── buf.yaml                  - buf module: STANDARD lint, FILE-level breaking rules
└── d2/
    └── common/
        └── v2/               - package d2.common.v2
            ├── d2_result.proto   - D2ResultProto gRPC wire shape, with TKMessageProto and InputErrorProto
            ├── health.proto      - CheckHealthRequest, CheckHealthResponse and ComponentHealth messages
            ├── jobs.proto        - TriggerJobRequest, TriggerJobResponse and JobExecutionData messages for
            │                       Dkron scheduled job RPCs
            └── ping.proto        - PingService liveness ping
```

## Consumed by

- **.NET** - each service or library project that references these files compiles them with `Grpc.Tools` (MSBuild),
  including packages under `packages/dotnet/*`; the build generates the C# stubs
- **TypeScript** - `@dcsv-io/d2-protos` (Buf + `ts-proto` types and gRPC stubs generated from these protos; sources
  committed)
- **TypeSpec** - internal IDL tooling; not required for published packages

These `.proto` files are generated from a TypeSpec specification that is not part of this repository; each file starts
with an `<auto-generated>` banner, and a hand edit is lost at the next generation. The consumers above generate code
from them.
